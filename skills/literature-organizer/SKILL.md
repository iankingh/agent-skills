# literature-organizer

先讀目的地規則、現有分類與索引；不預設私人路徑、emoji 對照或主題子資料夾。只處理明確指定範圍；不因套用分類規格而批次改名無關筆記。

文獻屬性以目的地 `AGENTS.md` 或已確認的使用者規格為準；有白名單時，只使用允許欄位，不因舊稿、模板或來源附帶 metadata 就自行擴充。需要新增欄位時先詢問並取得使用者同意；不把文獻限制套到課程、永久筆記或日誌。缺資料不猜值；保留原建立日，純屬性清理不冒充實質內容更新。分類整併、額外屬性的保留／移除依已授權策略；移除前核對受影響查詢。未授權刪除原有資訊時先保留並釐清。明確逐位元複製或只改名時不改內容，交付時說明例外。新取得的發布日、長度、補充來源、閱讀方法與限制優先寫在正文，不自行新增查核屬性。

## 檔名與分類

- 僅移除可確認的匯出識別碼；使用者指定標題及正文完整標題優先，不用截斷檔名取代原標題。
- 沿用既有前綴、標籤與 MOC 語意；若已授權將分類整併到 tags，先核對同義及階層標籤、轉換不合法字元並去重，保留主題資訊。
- 改名前確認目標不存在；發生衝突時完整比對正文、程式碼、表格、來源與限制，不以檔案大小判定哪份可刪。
- 合併或移除只在授權範圍內，保留獨有內容與原稿差異；以原檔名、識別碼及正文核對連結，不按相似標題猜測。

## 驗收

記錄完整改名及分類對照，修復受影響內部連結與查詢，依目的地規則更新導航。確認沒有漏收、重複或非預期正文變更；備份與過程資料依目的地政策處理。
