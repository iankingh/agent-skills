# Obsidian：YT 筆記命名與索引

使用者要求將影片筆記存入 Obsidian 時讀取本檔。目的地、分類、命名及統計以使用者指定的筆記庫與作業當時的實際檔案為準。

## 目的地

- 筆記庫路徑使用使用者指定或當前對話已確認的位置。未確認或路徑不存在時先詢問，不自行建立筆記庫。
- 辨識目的地既有筆記、MOC（主題索引）、附件與備份位置；無法判定本次需要使用的存放位置時先詢問，不自行建立整套目錄。原文匯入僅確認來源、完整標題與目標位置，不擴大為索引維護。

## 原文匯入：來源判斷與完整標題


使用者提供已整理好的筆記時，只需讀取足以判斷主要來源與完整標題的內容，不必重新取得影片或改寫正文。

- **先判斷來源**：主要來源是 YouTube 影片的筆記，加上 `▶️ YT-`。不能只因文章的參考資料含 YouTube 連結，就把它當成影片筆記；其他來源沿用適合該類型的既有前綴。
- **標題優先順序**：使用者明確提供的完整標題 → 文件內的完整一級標題 → 原檔名。前兩者可用時，不以可能截斷的匯出檔名取代；僅能使用原檔名時，移除可確認的匯出識別碼與副檔名後作為標題。
- **命名格式**：`▶️ YT-使用者的完整標題.md`。保留原有作者、標點、副標題及 `（筆記）` 等文字，不自行縮寫、換詞、重新排列或插入主題分類。標題已有正確前綴時不重複添加。
- **範例**：`Fred 聊 SOLID 設計原則｜五個原則環環相扣：SRP 是前提、OCP 是目標、DIP 是做法，LSP 與 ISP 守住介面（筆記）` → `▶️ YT-Fred 聊 SOLID 設計原則｜五個原則環環相扣：SRP 是前提、OCP 是目標、DIP 是做法，LSP 與 ISP 守住介面（筆記）.md`。
- **檔案操作**：從外部匯入時保留來源檔、將原文複製至使用者指定或既有慣例確認的筆記目錄；只要求修改庫內檔名時，重新命名該檔案。保留正文、標題、既有 metadata、連結及換行，不為符合下方範本而改內容。目的檔若已存在，先確認是否為同一檔案或相同內容，不覆蓋不同內容。

只做原文匯入或改名時，到此規則與內容一致性驗證即完成；不執行下方 metadata、索引、統計與歷程更新，除非使用者另有要求。

## 新內容整理的命名

使用者已指定標題時原樣保留；未指定時依 [note-structure.md](note-structure.md#標題與圖示) 產生單篇、課程章節或總頁標題。所有新影片筆記檔名用 `▶️ YT-完整標題.md`，正文標題配置適合的 emoji。已有檔名優先保留，不因新規則批次改動。

普通影片摘要不自動新增永久筆記。若筆記庫使用主題分類，依內容歸類，不僅以 YT 作為內容主題。影片中的 Prompt 筆記也使用影片前綴，沿用目的地的標籤慣例，保留可識別 YouTube 與 Prompt 來源的資訊；既有其他前綴的筆記不批次改名。

附件與備份採用筆記庫既有或使用者指定的位置。需要保存但位置未明時先詢問；備份用當次日期與用途區分，不覆蓋既有備份。

## 新內容整理的 Metadata 與內容

本節與下方索引維護僅適用於新建或明確要求重整的筆記，不套用於原文匯入。

沿用既有筆記的欄位與格式，來源、作者及日期依本篇影片與實際整理時間填寫。更新原篇時保留原建立日期與使用者內容，不套用固定的筆記類型、標籤或狀態值。

以目的地既有格式記錄可確認的來源、頻道／作者、發布日期、讀取日期、長度及查核範圍；未知的發布日期或長度不猜測。筆記庫使用 `verification` 時，記錄實際讀取方式、涵蓋範圍、是否聽辨及未確認事項；未有該欄位時，在正文保留相同查核資訊。將技能中的完成程度對應到筆記庫既有狀態慣例，不因文稿已寫完就標記完整。

正文依 [note-structure.md](note-structure.md) 的指定順序呈現；來源不足時明示缺漏，不補造內容。原文匯入仍保留既有正文與 metadata，不套用新結構。

內部連結只指向存在且可唯一定位的筆記或索引，顯示文字可簡短；不要為補上連結而自行建立 MOC。外部來源與時間使用 Markdown 連結。

## 更新既有入口

YT 總覽、主題 MOC、首頁、統計及整理歷程，僅在既有整理流程包含該檔案，或使用者要求時更新。讀取後做局部更新，保留原排序、折疊區與查詢；若使用者要求建立新索引，先確認名稱與位置。

- **YT 總覽**：沿用現有分類與顯示方式；有收錄數時依實際成員更新，保留原本以來源欄位或標籤辨識影片的查詢。
- **主題 MOC**：依實際內容選擇，核對目前檔名與段落；Prompt 題材依既有規則更新相應索引。
- **首頁與整理索引**：僅更新本次影響的現行數量、狀態或手動清單，保留自動查詢與入口結構。更新既有筆記不增加篇數。
- **整理歷程**：新增本次日期、筆記連結、讀取方法、限制及必要的備份入口，保留歷史正文與當時統計。

統計依實際筆記目錄、來源及 metadata 重算，不在舊數字上直接加一。僅計算相應範圍的 `.md` 筆記，排除附件、技能文件與索引；筆記庫若分文獻與永久筆記，兩者分開計算。YT 與 Prompt 集合可能重疊，不直接相加。

確認實際 YT 成員與手動總覽一致，連結解析也考慮既有 aliases；單純清點檔名 `YT-` 不足以涵蓋以其他前綴命名的影片筆記。若筆記庫有 Prompt 分類，統計與查詢同時涵蓋實際使用的 Prompt 標籤及既有檔名前綴，避免漏掉採用影片前綴的新筆記。
