# 來源追溯與說法查核

適用於找原作、補作者／日期及查核文獻中的重要說法。先確定本次要查什麼，不把單篇整理擴大成無關的全面研究。

## 追溯來源

- 從使用者提供的文字、原連結與引用找原作者；轉載頁可作線索，但不能單靠署名宣稱直接讀過原作。
- 記錄「原作 → 轉載／社群整理 → 官方或研究核對」的關係。官方資料可核對技術內容，不能因此證明轉載者的作者歸屬。
- 比對標題、正文、帳號／作者及引用。保留原作日期、轉載日期、更新日期與讀取日期的區別；畫面只顯示月日時，不擅自補年份。
- 有連接器先用連接器；文字擷取漏圖、日期或原頁讀不到時，可用支援的瀏覽器查看。遇到登入／權限等限制，說明已取得與缺少的部分，不憑主題補造。

## 查核關鍵說法

| 類型 | 核對項目 |
| --- | --- |
| 數字、成長與下降 | 統計對象、期間、分母、絕對量或比例、相對百分比或百分點 |
| 公司／產品案例 | 哪個團隊、產品、repository 或樣本；不要把局部實踐套到整間公司 |
| 效果與因果 | 作者自述、前後比較或對照實驗；指標改善不自動等於某一做法造成改善 |
| 工具能力 | 版本、平台、輸入形式、相依與限制；公開說明或示例不是本次實測 |
| 研究結論 | 研究年代、模型、任務與樣本；不把特定實驗寫成所有現行系統的硬限制 |

重複轉載相同說法不算多份獨立證據。重要差異保留各自前提；沒有證據的因果、能力保證或補全推論，標成未確認或整理者推論。

## 筆記與狀態

- 來源說法、直接核對結果、整理者補充分開呈現，引用放在支持的段落附近；不必每篇套固定查核表。
- `verification` 簡述實際讀到的正文、圖表、日期與限制。只有 alt／圖說、部分畫面或 README 時，不能宣稱看完圖表、完整影片或已測試程式。
- 缺原作而有可讀轉載時，清楚標記轉載歸屬；若使用者要求的核心內容仍缺，保留「待補充」。不能藉通用知識把缺來源的內容變成已查證。
- 多種取得方式都無法提供新證據時，停止重複嘗試同一限制，交付可用內容與明確缺口；需要使用者補素材時只指出實際缺少項目。

## 影片來源與技術示範

- 先分清本次要整理貼文說明還是影片本體。只有轉載文案時，可整理已取得的背景與作者說法，不能把未取得的核心講解寫成影片重點。
- 有字幕、逐字稿或可理解音軌時，依任務範圍閱讀；只有畫面時，可逐段查看實際圖卡並記錄涵蓋的主題與時間位置。分開註明哪些來自文案、圖卡或口述，抽看圖卡不等於完整聽辨影片。
- 轉載遇到限制時，可沿署名與連結找原作者的公開版本，核對作者、標題、主題及片段內容；時長相同只能輔助，不能單獨證明是同一支。合集中的單一片段按該段處理，不自行擴大為整套課程。
- 抽看位置標為約略時間，不當成精確章節起點。未取得時間就留待補，不按段落比例推算；無法驗證跳轉功能時保留原片連結與時間文字，不硬套其他平台的時間戳格式。
- 整理技術生態或示範時，區分原生 API、函式庫、程式語言、模擬方法及輸出流程；核對必要的版本與後端條件。依文件自行整理的分層圖另行標示，不冒充未取得的作者原圖。
- 示意候選數量、排序分數、流程乘法式及展示畫面，只支持其實際呈現的內容；未定義分母、校準方式或實驗條件時，不轉為成功機率、效能保證或固定設計參數。觀看示範也不等於已重製或實測。
