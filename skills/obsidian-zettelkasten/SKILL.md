# Obsidian Zettelkasten

使用者要求實際整理指定 Vault 時使用。僅討論知識管理方法時在對話中回答，不自行寫入。目的地採用本次指定或對話已確認的位置；先讀 `AGENTS.md` 及目標資料夾的既有筆記、模板與導航，不預設個人路徑、標籤清單或資料夾名稱。

## 先辨識內容與存放類型

| 素材與目的 | 處理方式 |
| --- | --- |
| 有總覽與章節、或明確指定的整套課程 | 先查既有課程資料夾、模板與索引，沿用首頁／章節／教材層級，不先套文獻模板 |
| 外部文章、書籍摘錄、獨立技術文件或單篇教學筆記 | 文獻筆記，保留作者觀點、來源與查核限制 |
| 使用者提煉的單一概念 | 永久筆記，以自己的話說明概念、邊界及適用條件 |
| 一組主題的查找入口 | MOC，只整理導航與關係，不重複搬入各篇正文 |
| 已成形的現有筆記 | 先檢查需要輕修、重整或可以跳過，不為套模板而重寫 |

### 整套課程

課程不必具備教材附件才可分流。先沿用目的地已有的課程首頁、章節與教材結構，保留完整標題及原章節粒度。首頁與章節的類型、序號及所屬課程欄位依既有模板，建立可往返的連結；不因來源是 YouTube、技術教學或影片清單就全部放進文獻目錄。

匯入驗收與學習完成分開。沒有使用者資料時，學習進度、完成日期留空，模板的預設完成值不能當成已學完的證據。課程數與課程筆記數另計，不重複算入文獻；只有使用者要求提煉概念時才另建永久筆記。

## 文獻筆記

文獻屬性以目的地 `AGENTS.md` 或已確認的使用者規格為準；有白名單時，只使用允許欄位，不因舊稿、模板或來源附帶 metadata 就自行擴充。需要新增欄位時先詢問並取得使用者同意；不把文獻限制套到課程、永久筆記或日誌。缺資料不猜值；保留原建立日，純屬性清理不冒充實質內容更新。分類整併、額外屬性的保留／移除依已授權策略；移除前核對受影響查詢。未授權刪除原有資訊時先保留並釐清。明確逐位元複製或只改名時不改內容，交付時說明例外。新取得的發布日、長度、補充來源、閱讀方法與限制優先寫在正文，不自行新增查核屬性。

先辨識主要來源與主題，再依 Vault 既有命名、資料夾、標籤及狀態慣例歸檔。來源若只是文章中的延伸影片，不因此將整篇改列影片筆記。

- 新摘要保留作者觀點與來源脈絡，區分原文、自己的思考及外部補充，不補造作者、日期或未讀到的內容。
- 閱讀文章時依 [文章圖表閱讀與轉寫](references/article-visuals.md)，納入實際可讀的表格與圖片。需要轉寫時，資料比較可用 Markdown 表格、流程與關係可用 Mermaid；看不到或無法辨讀的部分明記限制，不僅憑圖說宣稱讀完。
- 已整理原稿的匯入保留正文與原標題，只做已授權或專案明訂的必要屬性、連結及導航轉換；明確要求逐位元保留或只改名時，不加寫內容。
- metadata 沿用目的地的來源、作者、建立日期與狀態欄位。更新舊稿保留原建立日；只有匯入日可確認時，註明這是匯入時間，不推定原稿建立日。
- 缺主要來源或內容時依既有狀態標示待補充；原始摘錄尚未收斂時標示待整理。匯入成功不代表內容已完整查核。

## 永久筆記

以一個能清楚說明的概念為單位。保留自己的推論、使用條件、例子與限制，連回實際存在的來源筆記；需要時補上層、下層及相關概念。概念過大時先判斷是否應拆分，不只為湊卡片數量建立空頁。

aliases、成熟度與建立日期沿用 Vault 慣例；不僅因新增幾個連結就自動宣稱觀點成熟，也不將來源說法改寫成已驗證結論。

## MOC、屬性與雙向連結

選擇已存在且合適的主題入口，核對實際檔名、別名及段落。建立新 MOC 必須服務本次主題或使用者要求，不為了填入回連就建立空索引。

新增必要 wikilink 時同步更新兩端；連結目標不存在時保留未解狀態，不憑相似標題建立替代頁。引用、程式碼與外部 URL 不因內部整理而改寫。標籤沿用目的地既有語意與大小寫，已有明確授權或對應分類時不重複詢問。

主題導航放 MOC，整理索引追蹤待整理、待補充與維護狀態，歷程記錄本次實際操作與限制。統計依實際目錄、類型及可解析的 YAML 重算；來源分類可能交疊，不能直接相加，歷史日期與當時數量保留。

## 內容保留與驗收

備份與附件保留依使用者最新要求及目標 Vault 政策，不預設每次必須新增 ZIP。原稿只有摘要、仍含獨有資料或需保留原始版面時，不因已有筆記就視為重複；清理僅限已授權範圍，不重建已依政策清理的來源包。

寫入前先確認不會覆蓋不同原稿；批次過程資料放 Vault 外暫存區，依專案要求將有用對照與驗收收斂為 Markdown。完成前核對：

- 選對文獻、永久筆記、MOC 或課程層級，使用者指定範圍及原有內容未遺失。
- 必要 YAML 可解析、日期與狀態語意有來源；正文、程式碼、表格、外部來源與限制依本次模式保留。
- 內部連結可唯一定位，新增雙向關係兩端同步，課程首頁與章節可往返。
- 涉及更新的索引、查詢與現行統計範圍一致，沒有把回收或暫存副本算入。

交付可點擊的筆記連結，簡述本次實際整理範圍、驗證方法及未完成項目；不將未讀來源或未執行的練習寫成已完成。
