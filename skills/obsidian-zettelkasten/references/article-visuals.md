# 文章表格與圖片的閱讀、轉寫規則

適用於把文章、教學或單篇社群貼文整理為指定 Vault的文獻筆記，以及補讀既有筆記的圖表。一般排版或 metadata 輕修不必重新抓取來源；文章附帶影片也不因此變成全片整理任務。

## 閱讀範圍

- 整理文章時，正文、原生表格與內容圖片都在閱讀範圍內。純文字擷取成功，不代表附圖已讀完。
- 先辨識有哪些表格及圖片；排除導覽、廣告、作者頭像與推薦文章縮圖。封面、人物照片可合併註明已查看、無新增資料，不需硬轉成圖。
- **逐張實際打開內容圖片**，辨讀圖中文字、圖例、數值、箭頭、分組與註腳。alt、圖說、檔名及鄰近正文只能協助定位，不能代替看圖；OCR 也需對照圖面。
- 擷取結果漏圖、圖片延遲載入或 metadata 不全時，用可用的瀏覽器查看原頁與實際圖片；核對作者、日期時，區分頁面標示與自行推定。
- 只有貼上文字且沒有附圖時，先整理可取得內容；若原頁可讀則補看圖。受登入、安全限制或解析度阻擋時，記錄缺哪張及原因；缺少關鍵內容才請使用者補來源，不反覆索取已提供的檔案。

## 依資訊選格式

| 來源內容 | 筆記呈現 | 保留重點 |
| --- | --- | --- |
| 比較表、矩陣、欄位對照 | Markdown 表格 | 比較維度、必要列欄、條件、單位與註腳；過寬時依主題拆表 |
| 流程、決策樹 | Mermaid `flowchart` | 起訖、步驟、分岔條件、例外與回路 |
| 人員／系統間訊息順序 | Mermaid `sequenceDiagram` | 參與者、訊息方向、先後與回覆 |
| 狀態轉換或元件關係 | 合適的 Mermaid 圖型 | 狀態／元件、關係方向與條件 |
| 折線、長條或數值圖 | Markdown 數值表搭配解讀，必要時另作圖 | 軸、期間、基準、單位及可辨認數值；不要改成無法表達量值的流程圖 |
| 無新增資訊的封面／訪談照片 | 簡短閱讀紀錄或來源連結 | 不從照片推論談話內容，不要求裝飾性重繪 |

轉寫的目標是讓實質資訊可搜尋、可編輯，不能只貼原圖或寫「詳見圖片」。不強求每篇都有固定數量的表格或 Mermaid。

## 忠於來源

- 以使用者指定語言重述重點，避免整篇或大量圖中文字照搬；保留圖表必要資訊並遵守來源引用限制。
- 圖示中的流程、數據與宣傳性結論仍是來源說法。分開標示「原圖重繪」「整理者延伸」與「官方查核」，不能把教學示意變成公司正式流程、因果證據或實測結果。
- 不補畫原圖沒有的關係；若為方便理解新增步驟，明示是整理者補充。看不清楚的值標示未能辨讀，不靠正文或常識猜回去。
- 分清示意字數／分鐘數與測量數據、PR 占比與程式碼占比、估計與觀測；圖片和正文有衝突時保留差異，不默默選一邊。
- 每張轉寫圖表附近附原頁或原圖來源。閱讀紀錄可依圖片順序、檔名或主題對應；多張圖片或部分失敗時，用簡短清單／表格說明處理結果，避免重複內容。

## 整合與驗證

- 新文章依主題建立文獻筆記；補讀時更新原筆記，不另建同來源的圖片筆記。保留既有正文、查核與 `created`，實質補讀時更新 `updated`，補來源與 MOC 導覽；遵循目的地 AGENTS.md 或已確認規格的文獻屬性白名單，不新增查核屬性。
- 修改既有檔案前依使用者要求與目的地政策保留必要還原資料。只更新受影響的連結與整理歷程；沒有新增文獻時，不增加索引數量。
- 正文的來源查核段落記錄實際查看的正文、表格、圖片及缺口。文章有影片嵌入或訪談截圖，不等於已看完整影片／聽辨音軌。
- 新筆記缺少關鍵圖表時標為待補充；既有完成筆記新增補讀缺口時，明示未完成範圍，不任意推翻先前已完成部分。一般 metadata 輕修不需要重新判定來源完整度。
- 核對 Markdown 表格欄位、特殊符號與連結；Mermaid 核對節點、邊、分岔、訊息次序及 code fence。可用渲染器時預覽並修正錯誤；只做結構檢查時，不宣稱已渲染驗證。
- 結束時簡述補了哪些可編輯表格／圖、閱讀到哪裡及仍缺什麼，不把後續全文回補或批次整理其他舊筆記當成本次任務。
