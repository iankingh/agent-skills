# 模板與導覽

沿用目的地現有模板與規則；以下是無既定結構時的最小範例，不要求每頁都有相同段落或固定數量的圖表。

## 導覽

MOC 連到主題筆記與練習，來源對照列出檔案／URL、章節／頁碼與未取得內容。快速參考只收重要定義、公式與條件，每項連回解釋；常見誤解與弱項也連回概念。

## 文件概念

```yaml
source_pdf: <已核對的來源檔名；非 PDF 依目的地改用 source>
source_pages: <PDF 頁序與章節；紙本頁碼不同時另註>
keywords: [<一致的主題關鍵字>]
verification: <實際閱讀範圍及重要缺口>
```

正文使用簡短定義、必要的比較或步驟、例外與來源位置。原作觀點、外部資料與整理者推論分開；圖表轉寫附原頁，不把文字描述當成完整數據。

## 程式碼模組

```yaml
module: <模組名稱>
path: <專案相對路徑>
keywords: [<主題關鍵字>]
```

正文保留模組用途、關鍵檔案／符號、介面、實際資料流、相依、設定及驗證入口。未執行測試時只記錄檢查方式，不宣稱已通過。

## 練習

```markdown
## 情境或問題

> [!hint]- 提示
> 思考方向；不先洩漏答案。

> [!answer]- 答案與依據
> 回答、必要推理及來源頁碼／程式碼位置。

相關概念：[[實際存在的概念筆記]]
```

依目標混合回憶、應用、分析題，檢查答案能否從已讀來源支持；外加的練習情境需明示是整理者設計。
