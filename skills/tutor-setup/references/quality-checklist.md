# 品質檢查

只勾選實際檢查過的項目；不適用時略過並保留缺口。

## 來源與覆蓋

- [ ] 來源內容與版本已核對，不依檔名或 repo 目錄名稱推定主題。
- [ ] 教材章節／頁碼、或程式碼檔案／符號可由筆記回查。
- [ ] 摘要只作索引，重要說法及練習答案有支持它的原段落／程式碼。
- [ ] PDF 閱讀順序經原頁抽查，引用的圖表已實際查看單位、圖例及註腳。
- [ ] 跨章／跨模組推論與來源明說的內容分開，外部補充有來源。
- [ ] 已交代未讀、缺檔、解析失敗與未執行的驗證，沒有用背景知識填成原作。

## 學習與導航

- [ ] 主題覆蓋符合使用者目標，枚舉成員與重要例外未遺漏。
- [ ] 練習含回憶與應用，適合題材時加入分析；答案可折疊並附依據。
- [ ] MOC、概念／模組與練習相互連結，連結指向實際產物。
- [ ] 格式、屬性、標籤及語言符合目的地規則，沒有臆測學習完成狀態。

## 程式碼模式

- [ ] 架構與代表性呼叫／資料流由實際程式碼核對。
- [ ] 模組職責、介面、相依、設定及測試入口可追溯。
- [ ] 沒有為整理入門材料而擅自改動或執行專案。

## 交付

- [ ] 已查核修改檔案的 Markdown、frontmatter、code fence 與內部連結。
- [ ] 說明產物位置、實際驗證及剩餘缺口，不把抽查說成完整閱讀。
