# 文件閱讀、索引與證據

用於 PDF 與長文件轉學習筆記；依文件內容選擇處理方式，不預設轉 Markdown 就能改善理解，也不以頁數斷言整份文件能否放入模型上下文。

## 解析與原頁核對

- 保留原始文件、版本、章節與 PDF 頁序；文字擷取時保留分頁。掃描頁沒有文字層時才選擇合適的 OCR 或視覺閱讀方式。
- 文字型文件可先擷取文字，再抽查原頁的閱讀順序、跨頁段落與公式。先看封面、目錄及分布於中後段的代表頁，不能把抽查寫成已讀完整本。
- 對筆記實際使用的每張圖表，查看原圖並核對標題、軸、單位、圖例、註腳及數值；圖說、alt 與 OCR 文字僅輔助定位。圖表清單尚未盤點完整時，明示閱讀範圍。
- 表格轉 Markdown 時核對列欄、合併儲存格與註腳。圖表文字描述不是原始數據；僅有描述時可畫概念示意，不能宣稱精確重建數值圖。
- 解析失敗先針對缺頁換可用方式；若仍無法取得，列出缺頁／缺圖與影響，不用常識補成原文。

## 長文件索引

- 依文件長度與任務決定直接閱讀或按章節處理，不固定套用同一個 token／頁數上限。
- 章節索引保留「章節、頁碼、簡短摘要、關鍵字、相關概念與原文位置」。保留定義、反例、限制與跨章節引用，避免摘要只剩結論。
- 摘要用來找內容；作答與出題時取回相關原段落及圖表，核對證據是否支持答案。找不到時說明缺口。
- 跨章節問題需列出各章證據與它們的關係。來源沒明說的關係標為整理者推論，補充教材另附來源。

## 可追溯輸出

在現有筆記屬性中按需補 `source_pages`、`verification`，並在關鍵說法附近附頁碼／章節。`source_pdf` 檔名須與來源對照表一致；非 PDF 來源依既有欄位慣例保留 URL 與標題，不虛構 PDF。

例如原文位置可記成「來源檔案，第 18–20 頁（PDF 頁序），第 3 節」；紙本頁碼不同時另列標籤。記錄已讀正文、實際查看的圖表、未讀內容及補充來源，不把輸出筆記完成等同完整閱讀或學會來源。

## 驗收

- 從筆記抽查重要定義、一道跨章問題及一張實際引用的圖表，能回到支持它的原頁；沒有相應題材時不強湊案例。
- 確認摘要、檢索片段與圖表數值沒有脫離前提；保留未能核對的項目。
- 驗證過程只記錄實際完成的閱讀／工具結果；不宣稱未做的 OCR、渲染或完整實驗已通過。
