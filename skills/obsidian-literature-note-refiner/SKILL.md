# obsidian-literature-note-refiner

讀取目的地規則及指定文獻；依需要輕修或重整，完整頁跳過，明確屬性遷移或補讀要求除外。若已安裝 `obsidian-note-refiner`，沿用其文獻分支；本技能亦可獨立使用。

文獻屬性以目的地 `AGENTS.md` 或已確認的使用者規格為準；有白名單時，只使用允許欄位，不因舊稿、模板或來源附帶 metadata 就自行擴充。需要新增欄位時先詢問並取得使用者同意；不把文獻限制套到課程、永久筆記或日誌。缺資料不猜值；保留原建立日，純屬性清理不冒充實質內容更新。分類整併、額外屬性的保留／移除依已授權策略；移除前核對受影響查詢。未授權刪除原有資訊時先保留並釐清。明確逐位元複製或只改名時不改內容，交付時說明例外。新取得的發布日、長度、補充來源、閱讀方法與限制優先寫在正文，不自行新增查核屬性。

- 保留原標題、原建立日期與來源脈絡；輕修屬性不重寫正文，原稿匯入不重新摘要。
- 重整時用使用者指定語言收斂重點，區分原作與補充；指定補讀圖表時實際查看，不憑標題或圖說補造。
- 作者未知留空，來源未取得保留缺口；純屬性清理不自行提升或降低完成狀態。
- 只連到實際存在的筆記，依目的地規則更新 MOC 及雙向連結。驗證 YAML、Markdown、保留內容與已授權刪除項目，交付可定位的筆記及限制。
